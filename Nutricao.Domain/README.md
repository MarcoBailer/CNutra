## Criar uma nova rotina/migration
```
Add-Migration '{nomedaMigration}' -s Nutricao -project Nutricao.Shared.Data
```

## update rotina/migration
```
Update-Database '{nomedaMigration}' -s Nutricao -project Nutricao.Shared.Data
```

## update rotina/migration
```
Remove-Migration '{nomedaMigration}' -s Nutricao -project Nutricao.Shared.Data
```
